# TransMate · macOS Minimal Workbench

独立的静态 UI 概念稿，不连接现有业务逻辑。

## 这个方向

它把 TransMate 设想为一个原生桌面工具，而不是网页仪表盘：

- 原生窗口标题栏、统一半透明工具栏和 macOS 交通灯；
- 左侧为来源列表 / 项目资源，中间始终是当前文件的高密度翻译表格；
- 右侧检查器只在需要查看单条上下文时出现，可以完全隐藏；
- AI/API 从标题栏按需打开一个轻量弹出面板，不占用固定工作区；
- 底部只保留选择状态、自动保存和一个主操作。

## 运行

直接打开 `index.html`，或从项目根目录启动静态服务后访问：

`http://127.0.0.1:4173/ui-concepts/macos-workbench/`

## 可交互内容

- 点击「AI 连接」打开 / 关闭 AI 引擎设置；
- 点击右上角检查器图标，可显示或隐藏右侧检查器；
- 切换翻译、审校、检测模式；
- 勾选表格行会同步底部选择数量；
- `⌘/Ctrl + K` 打开命令面板；`⌘/Ctrl + Enter` 模拟发起翻译任务。
