# TransMate Native Workbench Concept

独立的静态 UI 概念稿，不连接现有业务逻辑。

## 方向

“桌面原生生产力工具”而非通用 SaaS 面板：窄活动栏、项目文件栏、文档标签和紧凑的翻译数据网格共同构成稳定的工作台。颜色仅用于识别文件、列、状态和当前操作；AI/API 通过顶部入口按需打开，不占用持续性的右栏。

## 运行

直接在浏览器中打开 `index.html`，或从项目根目录启动本地静态服务后访问：

`http://127.0.0.1:4173/ui-concepts/native-workbench/`

## 交互

- 点击“AI 引擎”打开独立配置面板；支持 Escape 关闭。
- 点击批次设置标题折叠高级区块。
- 勾选表格行会更新底部的已选数量。
- `Ctrl/Cmd + K` 显示命令提示；`Ctrl/Cmd + Enter` 模拟提交翻译任务。
